# FINIX Core Banking — Initial Development Preview (v0.1.0-dev)

> **DRAFT release notes. Publish as a GitHub _pre-release_ only after the checklist below is satisfied.**
> This is a development sandbox. It is **not** a bank, **not** production-ready, holds fictional data only, and makes no regulatory or security-certification claims.

## What's in this preview

* **Responsive Next.js dashboard**: accounts, transactions, transfers, sandbox cards, investments (sample/market data), notifications, light/dark themes.
* **Spring Boot REST API** with OpenAPI (dev profile) and JWT-protected endpoints.
* **PostgreSQL double-entry ledger**: derived balances, balanced and immutable journals, Flyway migrations.
* **Keycloak authentication**: OIDC Authorization Code + PKCE, FINIX-themed sign-in and registration with e-mail verification, session expiry handling.
* **GBP internal transfers** between a customer's own accounts, with idempotency keys, audit events and a transactional outbox (no dispatcher yet).
* **Sandbox virtual cards**: freeze/unfreeze, limits, simulated authorisations (no card numbers, no ledger postings).
* **Real-time SSE notifications** after committed changes.
* **Docker environment**: `docker compose -f docker-compose.yml -f docker-compose.full.yml up --build -d`.
* Optional integrations: Twelve Data market data, Alpaca **paper** trading, Logo.dev merchant logos.

## Known limitations

See the [README limitations](../../README.md#project-limitations) and [SECURITY.md](../../SECURITY.md#10-production-readiness). In short: no regulatory authorisation, no external payments, no KYC/AML or fraud controls, no backups/DR, no outbox dispatcher, development-only Keycloak realm and demo features, CI not yet verified on GitHub, and two CRITICAL Spring Framework 6.2.19 advisories (fix only in Spring Framework 7) that remain open.
